Finding out where abducted Ukrainian children ended up is slow, repetitive OSINT work. A lot of the data is on Russian social media, some is in leaks that we have exclusive access to, and the data needed for context is in articles from local Russian authorities. The search also means running photos through face search and cross-referencing records.

I built a toolkit that lets AI agents do the legwork of that search while keeping every step checkable.

A case starts from one of two kinds of material:

  • Lists: children’s names and dates of birth. The original rows stay untouched. A model recognises unfamiliar column headers, Ukrainian names get a separate Russian spelling for searches, and each row is enriched one field at a time.
  • Pictures: group photos where nobody is named. A face-detection model cuts out every face, and the crops go to face search for profile leads.

Both routes end the same way: raw captures, structured leads, queues of next steps and a report built from saved evidence.

Each tool is an agent skill: a script plus a short Markdown file that says when the agent may run it, what it takes in, what it saves and which safety rules apply. The workspace has the same kind of contracts on a larger scale: one file for the evidence rules, one for the workflow and one per case for its scope and risks.

An orchestrator works as a traffic controller. It reads what has already been saved, works out which stage each person is at and writes queues of what is eligible next.

The biggest risk in this work is false certainty. A similar face, a shared surname or a phone number that turns up in two records can make two different people look like one. So uncertainty is part of the output:

  • Every finding is unverified, possible, likely or confirmed, and moves up only when the evidence gets better, not just when there is more of it.
  • Identity confidence (is this the same person?) is scored separately from information confidence (is this claim reliable?).
  • Conflicting names or dates of birth stay visible, each with its source, and empty searches are logged too.

Every claim can be traced back to its input, timestamp, tool output and saved file, so a report can be regenerated from the evidence instead of from memory. Pages are archived before they’re cited, because Russian websites disappear quickly.

To give my teammates access without the command line, I wrapped the workflow in a local web app.
